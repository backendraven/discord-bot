# Discord Bot — Кубик и Монетка

Простой Discord-бот на Python.  
Учебный проект, демонстрирующий работу с библиотекой `discord.py`, командами и обработкой событий.

## Возможности

| Команда    | Описание                              |
|------------|---------------------------------------|
| `!привет`  | Бот здоровается с пользователем       |
| `!кубик`   | Бросает кубик (случайное число 1–6)   |
| `!монетка` | Подбрасывает монетку (орёл / решка)   |
| `!помощь`  | Показывает список доступных команд    |

При вводе неизвестной команды бот сообщает, что нужно написать `!помощь`.

## Технологии

- Python 3.8+
- discord.py
- Переменные окружения для хранения токена

## Установка и запуск

### 1. Клонирование

```bash
git clone https://github.com/your-username/discord-bot.git
cd discord-bot
```

### 2. Установка зависимостей

```bash
pip install discord.py
```

### 3. Настройка токена

Создайте бота в [Discord Developer Portal](https://discord.com/developers/applications) и скопируйте токен.

Задайте переменную окружения:

**Linux / macOS**

```bash
export DISCORD_TOKEN="ваш_токен"
```

**Windows (PowerShell)**

```powershell
$env:DISCORD_TOKEN="ваш_токен"
```

Токен не должен храниться в коде и не должен попадать в репозиторий.

### 4. Запуск

```bash
python bot.py
```

После запуска в консоли появится сообщение:

```
Бот <имя_бота> готов к работе!
```
